# Veda, terminal based editor

## Rules for AI agents
- Make your code as simple as possible. Oversimplifying is better than
  overcomplicating.
- Keep your explanations simple. Speak in plain language. Give examples.
- Keep your answers short and to the point.
- Do not commit the code to git without explicit request.
- Do not make changes to the code without explicit request.
- This project uses tabs for indentation. Run `gofmt -s -w .` before commiting the code.
- Code examples you receive verbatim are often part of a proprietary codebase.
  If you use these pieces of code, change the name to avoid including
  proprietary code in this project.
- Use `make` to build.
- To run all tests use `make test`. Note it can take long time.
- To run a specific test, use `go test`.
