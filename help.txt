Veda - A terminal-based text editor

USAGE:
    vd [OPTIONS] [FILE|DIRECTORY]

OPTIONS:
    -d          Enable debug logging
    -t          Enable trace logging
    -c, --changes
                Open the project changes buffer for DIRECTORY (default: .)
    -log PATH   Set log file path (default: /tmp/veda.log)
    -h, --help  Show this help message

NOTE:
    In-editor help is comprehensive and always up-to-date. After launching Veda:
      :help       - Overview, modes, key bindings, commands
      :help-keys  - Auto-generated list of all key bindings

    These commands are the primary source of truth for using Veda.
